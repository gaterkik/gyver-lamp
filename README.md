# 🔥 Smart Lamp C6 (Умная Огненная Лампа)

[![Platform](https://img.shields.io/badge/Platform-ESP32--C6%20(RISC--V)-E7352C?style=flat-square&logo=espressif)](https://www.espressif.com/en/products/socs/esp32-c6)

[![OTA](https://img.shields.io/badge/Cloud%20OTA-GitHub%20Releases-22c55e?style=flat-square&logo=github)](https://github.com/gaterkik/gyver-lamp)

[![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)](LICENSE)

Современная умная светодиодная лампа с атмосферными эффектами (живой огонь, матричный дождь, светлячки, ночник) на базе микроконтроллера нового поколения **ESP32-C6 (Super Mini)** с архитектурой **RISC-V**, поддержкой **Wi-Fi 6** и полностью **автономным облачным обновлением прошивки через GitHub**.

Проект спроектирован как подарочное устройство: лампа работает автономно, дружелюбна к пользователю любого уровня технической подготовки и позволяет создателю дистанционно обновлять прошивку и добавлять новые эффекты через интернет без проводов.

## ✨ Ключевые возможности

### 🌐 Дистанционное обновление через GitHub (Cloud OTA)
* **Работа за любым роутером (NAT):** Лампе не нужен статический белый IP-адрес или проброс портов. Она использует исходящее защищенное соединение по HTTPS.
* **Бережный пользовательский опыт (Zero-Disruption):** Если лампа включена, она никогда не начнет обновление принудительно, чтобы не прерывать работу ночника. Автообновление срабатывает только в режиме ожидания (когда лампа выключена), либо вручную по кнопке в веб-интерфейсе.
* **Мягкая неслепящая индикация загрузки:** В процессе скачивания прошивки светодиодная матрица на комфортной яркости (~15%) плавно заполняется снизу вверх бирюзовым цветом в реальном времени.
* **Аппаратный «Анти-кирпич» (Dual-Slot Rollback):** Прошивка скачивается во второй независимый раздел памяти (`app1`). Если новая версия зависнет на старте, загрузчик ESP32 автоматически вернет предыдущую проверенную версию.

### 📟 Сетевое обнаружение и вывод IP
* **Единый адрес `http://lamp.local`:** Протокол mDNS (Bonjour) позволяет открывать пульт управления с iPhone, Android, Mac и ПК без ввода цифр IP.
* **Бегущая строка IP на матрице:** В прошивку встроен легковесный шрифт 3×5. При каждом подключении к Wi-Fi лампа один раз мягко выводит свой текущий IP-адрес бегущей строкой прямо на диодах.
* **Captive Portal (`Lamp-Setup`):** При первом включении или переезде на новую сеть лампа поднимает собственную точку доступа `192.168.4.1` со всплывающим окном для выбора домашнего Wi-Fi за 30 секунд.

### ⚡ Аппаратная безопасность и управление
* **Программный лимитер тока (2.0A):** 256 диодов на полной белой яркости способны потреблять свыше 8 Ампер. Прошивка рассчитывает энергопотребление каждого кадра на лету и пропорционально масштабирует динамический диапазон. Лампу можно безопасно питать от любого стандартного телефонного адаптера (5В 2А).
* **Сенсорное управление (TTP223):**
  * **1 касание:** Плавное включение / выключение.
  * **2 касания:** Мгновенное переключение эффектов по кругу.
  * **Удержание:** Плавное диммирование яркости с отчетливой индикацией упора (короткий нырок в темноту на максимуме и яркая вспышка на минимуме) и фиксацией на границах без самопроизвольного отскока.
* **Энергонезависимая память (NVS):** Все настройки (состояние, яркость, выбранный эффект, цвет ночника, Wi-Fi) сохраняются во флеш-память с отложенной записью (Debounce), продлевающей срок службы микросхемы.

## 🔌 Схема подключения (Hardware Pinout)

Компоненты:
1. **ESP32-C6 Super Mini** (RISC-V 160MHz, 4MB Flash).
2. **Гибкая светодиодная матрица WS2812B 16×16** (256 адресных RGB диодов).
3. **Сенсорная емкостная кнопка TTP223** (красная/синяя плата).
4. **Блок питания 5V 2A** (USB Type-C или внешний).

| Пин ESP32-C6 | Подключение | Описание |
| :--- | :--- | :--- |
| **GPIO 2** | `DIN` матрицы WS2812B | Линия данных матрицы (прямое подключение 3.3V) |
| **GPIO 1** | `IO / OUT` кнопки TTP223 | Вход сенсора (внутренняя подтяжка `INPUT_PULLDOWN`) |
| **5V / VBUS** | `+5V` матрицы и вход питания | Силовое питание 5 вольт |
| **3V3** | `VCC` кнопки TTP223 | Питание емкостного сенсора 3.3V |
| **GND** | `GND` матрицы, кнопки и БП | Общий провод (земля) |

> [!TIP]
> Резистор на линии данных `GPIO 2 -> DIN` не требуется, так как логика ESP32-C6 (3.3В) стабильно управляет матрицей WS2812B при прямом подключении.

## 🎨 Список встроенных эффектов

1. **🔥 Живой Огонь:** Процедурный огонь с тепловой картой, реалистичными восходящими языками пламени и затуханием.
2. **🟢 Матричный Дождь:** Знаменитый цифровой дождь из к/ф «Матрица» с яркими зелеными каплями и затухающими хвостами.
3. **✨ Светлячки:** Хаотично мерцающие золотистые огоньки в ночи с мягким угасанием.
4. **💡 Ночник / Светильник:** Равномерная заливка выбранным цветом (по умолчанию теплый уютный янтарь `#FFAA33`, настраивается через Color Picker в веб-интерфейсе).

## 📱 Веб-интерфейс лампы

Веб-страница адаптирована под мобильные телефоны и доступна по адресу **`http://lamp.local`** (или по IP-адресу лампы в локальной сети):
* Тумблер питания ВКЛ / ВЫКЛ.
* Переключатель активного эффекта.
* Плавный ползунок яркости (5–255) с отображением в процентах.
* Палитра выбора цвета ночника (Color Picker).
* Блок статуса: IP-адрес, уровень сигнала Wi-Fi (dBm), время непрерывной работы (Uptime) и кнопка *«Показать IP на лампе»*.
* **Блок Cloud OTA:** Проверка и установка обновлений из интернета в один клик.
* **Инженерные настройки (под спойлером):** Смена ссылки на репозиторий GitHub и тумблер автообновления.
* **Локальный Web OTA:** Возможность прошить `.bin` файл напрямую из браузера при необходимости.

## 🛠 Сборка и компиляция прошивки

Для компиляции используется **`arduino-cli`** и ядро `esp32:esp32`:

```bash
# Установка параметров платы ESP32-C6 Super Mini
arduino-cli compile \
  --fqbn esp32:esp32:esp32c6:CDCOnBoot=cdc,PartitionScheme=min_spiffs \
  --output-dir ./build \
  ./gyver_lamp_ota
```

Готовый файл для прошивки: `gyver_lamp_ota.ino.bin`.

## 🚀 Как выпустить обновление для лампы через GitHub

1. Скомпилируйте новую версию прошивки и увеличьте номер версии в коде `#define FIRMWARE_VERSION "1.0.X"`.
2. Поместите скомпилированный бинарник `gyver_lamp_ota.ino.bin` в корень этого репозитория.
3. Обновите файл **`version.json`**:
   ```json
   {
     "version": "1.0.X",
     "url": "https://raw.githubusercontent.com/gaterkik/gyver-lamp/main/gyver_lamp_ota.ino.bin",
     "changelog": "Описание новинок: новый новогодний эффект и улучшенная плавность!"
   }
   ```
4. Отправьте изменения в репозиторий:
   ```bash
   git add version.json gyver_lamp_ota.ino.bin
   git commit -m "Release v1.0.X: New features"
   git push origin main
   ```
5. Лампа автоматически обнаружит обновление при следующей проверке!
